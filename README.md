# Change Blazers Website

My website for all things related to what I do and what I can offer.

## Project structure

```
.
├── index.html      # Home page
├── css/
│   └── style.css   # Site styling
├── js/
│   └── script.js   # Site behaviour
└── assets/         # Images and other static files
```

## Running locally

No build step is required — this is plain HTML, CSS, and JavaScript.

Open `index.html` directly in a browser, or serve the folder locally, e.g.:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
