# Blog cover images

Drop each post's cover image here, named after the post's **slug** (same slug
used in its `_posts/` filename), keeping whatever extension the image already is
(`.jpg`, `.png`, `.webp`, etc.) — you don't need to convert anything.

Once a file lands here, add an `image` line to that post's front matter
pointing at it, e.g.:

```yaml
---
title: "Change Management Poem"
date: 2022-12-24
read_time: 1
excerpt: "..."
image: /assets/blog/change-management-poem.jpg
---
```

The post page and the blog list will pick it up automatically — no other
changes needed. Posts without an `image` line just render without one, so
you can add these gradually.
